1 · Come è fatto

Il Grande Quiz vive in tre posti. Il principio è uno solo: le soluzioni non sono mai in chiaro su Internet.

🌐 Il sito pubblicodanilodauria.github.io/grande-quiz — quiz con il timer, scheda, schermo, manuale, vademecum, download. Senza soluzioni.
+
🔒 La cassaforteIl file cassaforte.bin, dentro il sito ma cifrato (AES-256): soluzioni, correttore, presentazione a squadre, PDF delle risposte.
←
🗝️ La cartella privatagrande-quiz-PRIVATO: le soluzioni in chiaro. Solo sul vostro PC e su una chiavetta. Mai su GitHub.

La cassaforte si apre con la vostra password e poi con il codice a 6 cifre di Google Authenticator sul vostro telefono. La password e il collegamento con Authenticator li scegliete voi con lo strumento «Crea la cassaforte»: nessun altro li conosce.

Detto con onestàIl sito non ha un server: è fatto di sole pagine. Per questo il vero lucchetto è la password (cifratura AES-256 con 600.000 passaggi): senza di lei le soluzioni sono illeggibili anche per chi scarica il file. Il codice di Authenticator è un secondo controllo che l'area riservata chiede sempre, ma chi conoscesse la password e fosse un esperto potrebbe aggirarlo. Quindi: password lunga e solo vostra.

2 · Mettere al sicuro la cartella privata SUBITO

  1. Spostate grande-quiz-PRIVATO in Documenti (non dentro Documenti\GitHub: lì GitHub Desktop potrebbe vederla).
  2. Copiatela anche su una chiavetta da tenere in un cassetto: è la vostra copia di sicurezza delle soluzioni.
  3. Non inviatela per email, non mettetela in cartelle condivise o in un cloud pubblico.
Regola d'oroNel repository grande-quiz non si mette mai contenuto-riservato.json né i file delle soluzioni. Il file .gitignore del repository li blocca comunque, e le prove automatiche controllano che nel sito non ci sia nessuna soluzione.

3 · Pubblicare il sito su GitHub UNA VOLTA

Come per il Professore Digitale, ma più semplice: niente Release e niente file grandi.

3a · Creare il repository vuoto

  1. Su github.com → + → New repository.
  2. Compilate così:
    Create a new repository
    Repository namegrande-quiz ← esattamente così
    DescriptionIl Grande Quiz dell'Informatica — Danilo D'Auria
    VisibilitàPublic ← il sito gratuito funziona solo così
    README / .gitignore / Licenseniente ← ci sono già
  3. Create repository.

3b · Caricare con GitHub Desktop

  1. Spostate la cartella grande-quiz in Documenti\GitHub.
  2. GitHub Desktop: File → Add local repository… → Choose… → Documenti\GitHub\grande-quiz → Add repository.
  3. In alto: ⬆ Publish branch (la cartella sa già dove spedire). Attendete la fine (circa 10 MB).

3c · Accendere il sito

  1. Su github.com/danilodauria/grande-quiz → ⚙ Settings → Pages.
  2. Build and deployment → Source: Deploy from a branch. Sotto: Branch main e cartella /docs → Save.
  3. Dopo 1–3 minuti il sito è online: https://danilodauria.github.io/grande-quiz/. (Qui non servono regole né Actions particolari.)

4 · Creare la cassaforte delle soluzioni UNA VOLTA

Serve il telefono con Google Authenticator installato (Play Store o App Store, gratuito) e la cartella privata.

  1. Aprite con doppio clic Documenti\GitHub\grande-quiz\docs\riservato\crea-cassaforte.html (oppure dal sito: Area riservata → link «Crea la cassaforte»). Funziona anche senza Internet.
  2. Passo 1 — Scegli contenuto-riservato.json → dalla cartella grande-quiz-PRIVATO. Deve comparire «264 soluzioni del Grande Quiz, 66 del Quiz del Manuale…».
  3. Passo 2 — sul telefono: Authenticator → + → Scansiona un codice QR → inquadrate il QR sullo schermo. Compare GrandeQuiz (Danilo). Scrivete nel campo le 6 cifre che vedete: deve comparire «Collegamento riuscito».
  4. Sempre al passo 2: scrivete a mano il codice di emergenza (tipo XXXXX-XXXXX-XXXXX-XXXXX) qui sotto e spuntate «L'ho scritto».
    Codice di emergenza:
  5. Passo 3 — scegliete la password: una frase lunga che ricordate, almeno 12 caratteri, meglio 16+ (es. quattro parole e un numero). Ripetetela. Non scrivetela in questo libretto e non c'è modo di recuperarla.
  6. Passo 4 — 🔒 Crea la cassaforte. Il file cassaforte.bin finisce nella cartella Download; lo strumento lo riapre subito per verificarlo.
  7. Copiate cassaforte.bin in Documenti\GitHub\grande-quiz\docs\riservato\.
  8. GitHub Desktop: in basso a sinistra scrivete Cassaforte delle soluzioni → Commit to main → ⬆ Push origin.
  9. Dopo 1–2 minuti, sul sito: Area riservata → password → le 6 cifre. Si apre il cruscotto: la cassaforte funziona.

5 · Usare il quiz in aula

Dal sito o dal pacchetto offline (cartella estratta, doppio clic su index.html): Quiz. La maschera guida in sei passi:

PassoCosa si sceglie
1 · QuizIl Grande Quiz (264 domande) oppure il Quiz del Manuale FeniceOS (66: anche abbinamenti e domande aperte).
2 · ModalitàQuiz a tempo (una domanda alla volta), Scheda risposte (tutte insieme, come su carta), Schermo domande (da proiettare).
3 · DomandeTutte, per capitolo o per livello; tutte quelle scelte o solo alcune a caso; nell'ordine del libro o mescolate.
4 · TempoSecondi per ogni domanda: da 10 secondi a 5 minuti (cursore o scelte rapide 20 s – 5 min). Allo scadere: si passa avanti oppure solo un avviso. Suono negli ultimi 5 secondi, pausa, possibilità di tornare indietro. Per la scheda: tempo complessivo da 5 a 240 minuti.
5 · PartecipanteNome e cognome (obbligatorio), data, centro, gruppo, livello, note.
6 · ProntiRiepilogo e ▶ Inizia la prova.

Durante la prova il cerchio in alto mostra i secondi: verde, poi arancione negli ultimi 10, rosso negli ultimi 5. Con la tastiera: A–D (o 1–4), V/F, Invio. Se si chiude la pagina per errore, al ritorno compare «C'è una prova in corso» → Riprendi, con il tempo che era rimasto.

Alla fine: Esporta le risposte (.json). Il file (es. GrandeQuiz_Risposte_Giulia_Bianchi_2026-10-12_1030.json) contiene solo le risposte, i tempi e i dati del partecipante, mai le soluzioni. Raccoglietelo con una chiavetta, per email o in una cartella condivisa.

6 · Correggere nell'area riservata

  1. Area riservata → password → le 6 cifre di Authenticator (o il codice di emergenza, se avete perso il telefono).
  2. Correttore automatico: trascinate tutti i file .json nel riquadro (anche decine insieme). Compare la classifica con giuste, percentuale e punteggi per livello. Funziona anche con le schede esportate dalla vecchia «Scheda Risposte Interattiva».
  3. Cliccate un nome: scheda di valutazione con errori, risposte mancanti, risposte giuste e spiegazioni; le domande aperte sono a parte, da valutare a voce. Stampa la scheda per consegnarla.
  4. Esporta il riepilogo (CSV per Excel) per il registro dell'ente.
  5. Dal cruscotto si aprono anche: Presentazione e quiz a squadre (da proiettare), Grande Quiz con soluzioni e spiegazioni, Manuale interattivo con le risposte, e si scaricano i PDF delle risposte.
  6. Alla fine: 🔒 Chiudi l'area riservata. Si richiude comunque da sola dopo 20 minuti senza attività. Dopo 3 password sbagliate l'area aspetta prima di riprovare.

7 · Aggiornare in futuro OGNI VOLTA

Quando vi preparo una nuova versione (domande nuove o corrette, migliorie) ricevete le due cartelle aggiornate.

  1. Sito: chiudete GitHub Desktop, rinominate Documenti\GitHub\grande-quiz in grande-quiz-vecchia, mettete al suo posto la nuova, riaprite GitHub Desktop → ⬆ Push origin.
  2. Cassaforte (solo se sono cambiate le soluzioni): crea-cassaforte.html → nuovo contenuto-riservato.json → al passo 2 scegliete «Tengo il collegamento di prima», caricate la vecchia cassaforte.bin con la vecchia password: Authenticator e codice di emergenza restano gli stessi. Scegliete la password (anche la stessa) → nuova cassaforte.bin in docs\riservato\ → Commit → Push.
  3. Cartella privata: sostituite quella vecchia sul PC e sulla chiavetta.

Per rigenerare da soli il sito dai sorgenti (con Python 3): python3 strumenti/costruisci.py --privato ..\grande-quiz-PRIVATO, poi le prove: python3 tests/test_sito.py --privato ..\grande-quiz-PRIVATO (servono Playwright e Chromium).

8 · Sicurezza, in breve

  • Password lunga, solo vostra, mai scritta in file sul PC né in questo libretto.
  • Google Authenticator sul telefono; codice di emergenza scritto a mano e conservato con il libretto.
  • La cartella grande-quiz-PRIVATO solo sul PC e su una chiavetta; mai su GitHub, email o cloud pubblici.
  • Password dimenticata: nessun recupero, ma nessun danno — rifate la cassaforte con contenuto-riservato.json (capitolo 4).
  • Telefono perso: entrate con il codice di emergenza, poi rifate la cassaforte collegando il telefono nuovo (passo 2 «Primo collegamento»).
  • Account GitHub con la verifica in due passaggi attiva (vedi il libretto del Professore, capitolo 9).

Se qualcosa va storto

Cosa succedeCosa fare
Area riservata: «non è ancora stata creata»Manca docs/riservato/cassaforte.bin nel sito: capitolo 4, punti 7–8.
Aprendo con doppio clic: «sceglietela voi»Normale fuori da Internet: Scegli il file cassaforte.bin → docs\riservato\cassaforte.bin.
«Codice non valido» con le 6 cifre giusteOra del telefono o del PC sbagliata: impostatela automatica. Il codice vale 30 secondi (accettato anche quello prima e dopo).
«Troppi tentativi: riprovate tra…»Dopo 3 password sbagliate l'attesa cresce (fino a 5 minuti). Aspettate e riprovate con calma.
Il correttore dice «non è un file di risposte»Il file non viene dal Grande Quiz o è stato modificato. Fatelo riesportare al partecipante.
La presentazione non si apreIl browser ha bloccato la nuova scheda: consentite le finestre (pop-up) per il sito.
Il sito dà 404Capitolo 3c: Pages su main e /docs; repository Public; attendete 2–3 minuti.
GitHub Desktop rifiuta il PushVedi la tabella «Se qualcosa va storto» del libretto del Professore Digitale: stessi casi, stesse soluzioni.
