Come funziona

Dalla prima domanda al punteggio, in quattro passi

  1. Si preparaChi conduce sceglie il quiz, le domande e i secondi per ogni domanda.
  2. Si rispondeUna domanda alla volta, con il timer, oppure sulla scheda completa.
  3. Si consegnaLe risposte si esportano in un piccolo file .json, senza soluzioni.
  4. Si correggeSolo chi conduce, con password e Google Authenticator, ottiene punteggi e spiegazioni.
